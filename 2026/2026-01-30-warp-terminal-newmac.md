# Warp – daily terminal replacement

**Use case**
Leverage AI in terminal and speed up common CLI workflows without switching tools constantly.

**Setup path**
- Installed Warp
- Imported shell config and set up keyboard shortcuts
- Setup default as well Open AI API keys
- Used to install everything else on the new mac - homebrew,python,gh etc.

**Key insight**
Very little cognitive overload, much faster than copy pasting from Chatgpt, Can switch between english and CLI commands easily.

**Gotcha (if any)**
Some muscle memory from traditional terminals takes time to unlearn.
