# Manus – first agent workflow setup

**Use case**
Evaluate whether an agent framework can handle multi-step reasoning without heavy orchestration code.

**Setup path**
- Created a basic agent
- Defined a simple task chain
- Ran an end-to-end prompt

**Key insight**
👉 Opinionated defaults reduce setup friction more than raw flexibility for first-time agent workflows. Pretty nice to be able to create a website from the doc right away

**Gotcha (if any)**
Using the lite version is as good as ChatGPT but need the advanced for more comprehensive docs. Excel generator seems nice but need to try more complex sheets.
